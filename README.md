# Интернет‑магазин — учебный проект

Учебный проект интернет‑магазина на Django. Проект будет развиваться поэтапно в течение всего курса: на каждом уроке добавляются новые функции. В конце курса получается полноценное приложение для портфолио.

## Технологии

* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Контроль версий:** Git, GitHub (работа по методологии GitFlow)
* **Окружение:** виртуальное окружение Python (`venv`)

## Функциональность (на текущем этапе)

* Главная страница сайта.
* Страница с контактной информацией.
* Стилизация с использованием Bootstrap 5.
* Маршрутизация по методологии Django.
* Подготовка к реализации формы обратной связи (дополнительное задание).
